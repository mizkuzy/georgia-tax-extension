# Декларация малого бизнеса, Грузия

Расширение Chrome заполняет ежемесячную декларацию Small Business Income Declaration на rs.ge: поле 15 (доход с начала года) и поле 20 (доход за месяц). Курс USD/GEL берёт у NBG. Отправляете декларацию вы сами.

## Установка

1. Скачать проект:
   ```bash
   git clone https://github.com/mizkuzy/georgia-tax-extension.git
   ```
   Или без git: на GitHub «Code» → «Download ZIP» и распаковать.
2. `chrome://extensions` → включить «Режим разработчика».
3. «Загрузить распакованное» → папка `extension`.

## Как пользоваться

1. Залогиньтесь на https://eservices.rs.ge/.
2. Нажмите на иконку расширения — откроется панель справа.
3. Первый раз: «Выбрать папку» для истории доходов. Лучше вне проекта.
4. Введите дату и сумму дохода в USD за прошлый месяц (0 — дохода не было), нажмите «Заполнить декларацию».
5. Ответьте на вопросы в панели. Пока вы не ответили, расширение ничего не нажимает на сайте.
6. Проверьте поля 15 и 20 и отправьте декларацию.

При первом запуске в году расширение спросит про доходы прошлых месяцев.

## Данные

Файлы `2026.json`, `2027.json` в выбранной папке. Только на вашем компьютере. Записанные месяцы расширение не перезаписывает — исправлять вручную в файле.
